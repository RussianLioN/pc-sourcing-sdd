# T014: reviewed source coverage and reproducible operation — draft 1.0.0

Depends on accepted T013 integration. Product/user requirements are unchanged.

1. Reviewed capability per origin/path/adapter/retention basis/expiry, with source
   policy evidence distinct from robots. Pending and denied domains cannot fetch.
2. Tavily 429, Avito denial and NIX vpnerr stay blocked. No alternate tool, identity,
   IP, account, endpoint or implicit elapsed-time reset.
3. Multiple RF sources and Moscow fulfillment, 3–5 independent sellers per item
   where available; unknown seller independence never counts as confirmed.
4. Fresh leader recheck and original source dates; all full unconditional costs,
   quantity/completeness/condition/warranty/PAY evidence required for selection.
5. Repeatable cloud CLI user scenario and source-isolated recovery; no required bot
   token/hosting/new credential to run the core. Real operational e2e must be proven.
6. Coverage diagnostics explicitly name unavailable models/sources, unconfirmed
   sellers and manual Avito cases. No completeness or ban-free guarantee.
7. At least 50 diverse labelled cards, zero hard-rule violations, ≥95% classification
   and independently checked leaders are distinct from actual fresh multi-source e2e.

Before source calls: exact route plan, fresh public policy/feed review, fixed limits
and permission basis. Any new account/key/paid service/contact requires separate
explicit authorization. General website availability is not product-read permission.
